# CDinversiones-
 CDINVERSIONES     INVERSIONES TEGNOLÓGICA 
Créame una página de inversión de pesos argentinos con estás Funcionalidades a Implementar
Check-in diario (Recompensa cada 24 horas):
Un sistema donde el usuario pueda reclamar una recompensa fija de 100 ARS una vez cada 24 horas exactas, con un temporizador (cuenta regresiva) visible.
Identificación de usuarios:
Mostrar el nombre de usuario completo Gmail ingresado al registrarse claramente en el panel de administración a la hora de procesar cargas o solicitudes.
Flujo de Recarga Manual (Anti-automatización):
Al solicitar una recarga, la plataforma muestra los datos del negocio agregando este link de pago https://link.mercadopago.com.ar/mis4princesas2027El usuario realiza la transferencia desde su billetera virtual externa, sube el comprobante (captura) y un mensaje con su número de operación, quedando el estado en "Pendiente".
Panel de Administración (Gestión de Saldo):
Una sección exclusiva para administradores donde puedan ver las solicitudes pendientes, verificar el comprobante y tener botones rápidos o un formulario para "Agregar saldo" o "Quitar saldo" manualmente al usuario.
Compra Automática de Productos:
Al adquirir un producto, la plataforma valida en tiempo real si el usuario tiene el saldo suficiente:
Si tiene saldo: Se descuenta automáticamente y se registra la compra.
Si no tiene saldo: Se bloquea la compra y se muestra un aviso de saldo insuficiente.
Sistema de Retiros:
Un formulario donde el usuario ingresa su alias o CVU de destino y el monto a retirar. El sistema genera la solicitud y le indica al usuario que debe notificar al administrador por privado para recibir la transferencia.
Sistema de Referidos y Niveles (Multinivel / Afiliados)
Enlace Único de Invitación: Cada usuario cuenta con un enlace de referido personal desde su panel
Estructura de Niveles: El sistema registra la red de referidos (se puede configurar por niveles, por ejemplo: Nivel 1 - directos, Nivel 2 - invitados de tus invitados).
Comisiones Automáticas: Cada vez que un usuario de tu red realiza una recarga o compra un paquete, un porcentaje o monto fijo de comisión se acredita automáticamente al saldo de referidos del patrocinador.
Retiros de Referidos (Saldo de Ganancias)
 Es recomendable separar visualmente el Saldo Principal (para comprar paquetes) del Saldo de Referidos/Comisiones (ganancias listas para retirar). El sistema permite configurar cuántos paquetes puede comprar un usuario (por ejemplo, límite por tipo de paquete o cantidad máxima activa simultáneamente).
Validación en Tiempo Real: Al momento de adquirir un paquete, la plataforma valida:
Si el usuario cuenta con el saldo suficiente.
Si no supera el límite de paquetes permitidos.
Descuento automático y registro instantáneo de la compra. Agregar días y horarios de retiros de MARTES A VIERNES DE 10AM A 17 PM
